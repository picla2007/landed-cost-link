# Landed cost con lectura de links

1. Subí esta carpeta a un repo de GitHub (o corré `vercel --prod` dentro de la carpeta).
2. En Vercel → Settings → Environment Variables agregá `ANTHROPIC_API_KEY`.
3. Hacé un Redeploy.
4. Abrí la URL de Vercel, pegá un link de producto y tocá "Analizar".

Si una plataforma bloquea la lectura, la app avisa y podés cargar el precio a mano.
